# Contributor notes

Read [agent.md](agent.md) first.  Short version:

- **Errors are herbceptions only.**  Every function/lambda is explicitly
  `noexcept` or `throws`.  Never signal failure with `bool`, `int` or `errno`.
  Use `throw throws ::std::errc::...` and `catch throws (::std::error e)`.
- **Native flags:** `-fherbceptions -lherbceptions -fno-exceptions -fno-rtti
  -fno-unwind-tables -fno-asynchronous-unwind-tables -fno-ident`.  Do not use
  `std::thread`; use fast_io async I/O.
- **Wasm config:** `$HOME/cfgs/wasm32-wasip1-noeh-nomtg.cfg` (scripts fall back
  to `wasm32-wasip1-noeh.cfg`).  Keep the module import-free unless you
  deliberately opt into `wasi_fs.h`.
- **Text is UTF-8 + LF internally.**  Preserve the source encoding/BOM and only
  write CRLF when the source did or the user chose it.
- **Themes are only black or white.**  Indentation is only 2 spaces or tab.
- **Frontend source lives in `source/`.**  `docs/` is generated by
  `node build/build-web.mjs`; do not edit it by hand.
- The editor uses a real `<textarea>`; the wasm highlighter renders only the
  visible line window.
- Before finishing a change, run `build/build-all.sh` and walk the regression
  checklist in `agent.md`.
